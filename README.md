# Talkie English

تطبيق لتمرين التحدث بالإنجليزية:
- محادثة صوتية مع Sam (Gemini مجاني أو Claude)
- لعبة نطق، وتحدي دقيقة كلام
- عالم الأطفال: بطاقات كلمات، اسمع واختر، الحروف، فرقع البالون، لعبة الذاكرة، قل الكلمة
- قواعد الأطفال: الضمائر، am/is/are، a/an، المفرد والجمع، in/on/under، ترتيب الجملة
